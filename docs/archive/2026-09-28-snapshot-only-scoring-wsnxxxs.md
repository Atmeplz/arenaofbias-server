## 本轮目标

用户确认现有投票均为测试数据，没有需要保留的旧票；要求修复复查中的次要问题，并去掉分支名中的工具名字样。

## 改动

- 计分只用快照：没有身份快照的 legacy 票不参与计分；迁移前创建、没有快照的对局不能再投票；投票直接复制对局记录中的身份快照。
- 内容摘要：身份快照新增 `digest`（馆藏作品为入口页 SHA-256，投稿为全包 SHA-256），同一 ID 换成别的作品可从投票本身辨认。目录新增按作品缓存的 `entryDigest`，重复检测复用它。
- 目录刷新：开发包只在 `data.json` 的 stat（含 ctime）变化时重新计算哈希，同 mtime 的内容变化仍能检测。
- 旧快照：版本目录被清理后释放其内存快照；`catalog.at` 对缺失或被清理的目录返回 410，对局令牌不再提供内容。
- 测试：快照测试新增 digest 断言。
- 文档：README、API 契约写明快照计分、`digest`、只在写请求上携带版本头、清理后的 410；HANDOFF 更新。
- 本地分支 `codex/gallery-integration` 改名为 `gallery-integration`；README、HANDOFF 及两份 9-28 归档中的分支引用和「Codex desktop」字样按用户要求同步修改（对已落盘归档的正文更正，特此记录）。
- 本条归档随本轮英文提交一起提交。

## 决策

- 旧票不计分、不可更正：用户确认当前无真实历史投票。迁移仍把旧行标为 `legacy`，不伪造快照。
- 投票资格仍按当前审核状态与当前目录判断；内容摘要只用于溯源，不因摘要变化自动剔除旧票。
