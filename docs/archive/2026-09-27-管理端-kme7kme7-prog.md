## 本轮目标

在 arenaofbias-server 内构建独立的图形化管理端：服务端加用户管理 API 与 `/admin/` 静态伺服，`admin/` 目录入库一个零依赖单页应用（审核 / 作品 / 用户三页签，暗色墨色 + 亮色纸面仪器双主题），本地验证通过后提交 main。

## 改动

服务端（克制接入）：

- `server/config.mjs`：新增 `admin` 目录配置（`ADMIN_DIR` 环境变量可覆盖，默认 `<repo>/admin`）。
- `server/app.mjs`：
  - `serveSite` 增加 `/admin` 与 `/admin/*` 分支，经 `resolveInside(adminDir, …)` 伺服仓库内 `admin/`，优先于 `dist/` fallback；壳子 index.html 复用站点 CSP（`frame-src` 已含作品内容源，核验面板的试加载 iframe 因此可嵌入）。
  - 新增 `GET /api/admin/users`（仅 admin，返回 id/name/role/createdAt，不含 salt/hash）与 `POST /api/admin/users/:id/role`（仅 admin；非法角色 400、用户不存在 404、改自己 409；成功写 audit，action=`role`）。
- `server/auth.mjs`：新增 `list()`（列表按 `roleFor` 折算有效角色，环境变量管理员显示为 admin）与 `setRole(actor, userId, role)`（含防自降权）。
- `test/platform.test.mjs`：在 platform lifecycle 追加 1 个用例（未登录 401 / 非 admin 403 / admin 列表无敏感字段 / 提权降权即刻生效 / 自降权 409 / 非法角色 400 / 不存在 404 / audit 有 role 记录）。11 → 12 个用例。

管理端前端（`admin/`，原生 JS 零 npm 依赖）：

- `admin/index.html`：壳子，内联主题引导脚本（localStorage `admin-theme`，默认暗色），favicon。
- `admin/admin.js`：hash 路由单页（`#/review[/unverified|verified|questioned|log]`、`#/works`、`#/users`）；登录闸（未登录出登录表单，非 admin 出「需要管理员权限」）；审核页移植 platform-fusion 的队列与核验面板（上传检查 + 作者试加载报告 + 试加载 iframe + 登记模型/档位 + 通过/存疑必填原因/删除）；作品页为全部投稿表格（状态筛选 + 行内通过/存疑/删除）；用户页为账号表格（设为管理员/设为成员，自己那行禁用）。
- `admin/admin.css`：双主题共用一套角色变量。暗色（默认）token 取自 platform-fusion `style.css` 的 `[data-theme="dark"]`（#121211 底、#ecebe6 墨字、朱磦 #e46a50、圆角、柔和阴影、衬线标题）；亮色取自 Show1 `design-kit.css` 的 `--dk-*`（纸面 #d9ddda/#e8eae6/#eef0e9、墨 #1c2423、酸黄 #d9fb51 + 纸面文字级 accent-dim #718522、Bahnschrift 窄体 + 等宽仪器标签、零圆角 + 右下切角 + 3/4px 硬投影 #a2ad87、墨底顶栏 + 4px 酸黄下边线、面板左侧 3px 装订边）。
- `admin/favicon.svg`：同异字标（顺带消除了首次加载 favicon 404 的控制台红错）。
